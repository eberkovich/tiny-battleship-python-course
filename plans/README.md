## Workflow

1. Read `AGENTS.md`, `context/architecture.md`, this index, and the current
   stage file.
2. Before changing source, run the existing regression and prior-stage
   acceptance tests. A completed status is an expectation, not proof.
3. Implement only the current stage and keep its status accurate.
4. Complete the stage only after its definition of done and verification pass.
5. Record completion evidence, mark the stage complete here, then add and
   activate the next zero-padded stage file.

Completed stage files are normally frozen as historical records. If later work
invalidates one, explicitly reopen it or include the migration and regressions
in the active stage; do not silently rewrite history.

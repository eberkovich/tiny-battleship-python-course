# Своя функция

<!-- section: intro -->
## Несколько действий под одним именем

Иногда в программе нужно несколько раз выполнить одинаковые действия. Например, перед каждым сообщением вывести две вступительные фразы.

> [!EXAMPLE]
> **Пример:** программа выводит вступление перед каждым из двух сообщений.
>
> ```python
> print("Проверка связи")
> print("Приём!")
> print("Сообщение первое")
> print("Проверка связи")
> print("Приём!")
> print("Сообщение второе")
> ```
>
> ```output
> Проверка связи
> Приём!
> Сообщение первое
> Проверка связи
> Приём!
> Сообщение второе
> ```
>
> Две вступительные фразы записаны дважды. Если захочется изменить вступление, придётся исправить обе копии.

Можно описать эти действия один раз — в своей функции, — а затем вызывать её перед каждым сообщением. Если сообщений станет больше, не придётся копировать строки вступления снова и снова.

Ты уже вызывал готовые функции print, input и int. Теперь напишем собственную — show_intro, «показать вступление». Для описания своей функции используется новая запись с def; её части разберём сразу после примера.

Если пока не совсем понятно, в каком порядке Python выполняет строки с функцией, — это нормально. В следующей статье мы подробно проследим за выполнением программы. Сейчас обрати внимание на главное: вступление описано один раз, но используется перед обоими сообщениями.

> [!EXAMPLE]
> **Пример:** та же программа, но вступление описано в функции.
>
> ```python
> def show_intro():
>     print("Проверка связи")
>     print("Приём!")
>
> show_intro()
> print("Сообщение первое")
> show_intro()
> print("Сообщение второе")
> ```
>
> ```output
> Проверка связи
> Приём!
> Сообщение первое
> Проверка связи
> Приём!
> Сообщение второе
> ```
>
> Получился тот же вывод. Но теперь обе вступительные фразы записаны только в одном месте. Если изменить их внутри функции, новое вступление будет появляться при каждом вызове.

Первые три строки — **определение функции**: описание её действий.

- def начинает определение.
- show_intro — выбранное нами имя. Для него действуют знакомые правила имён: используем латинские буквы, а слова можно разделять знаком _.
- Пустые скобки () означают, что при вызове этой функции мы не передаём ей никаких значений.
- Двоеточие : стоит перед действиями функции.
- Две строки с print сдвинуты вправо на четыре пробела. Этот отступ показывает, что они относятся к функции. Такие строки называют **телом функции**.

Определение описывает действия, но ещё не выполняет их. Строка show_intro() **вызывает функцию**: Python выполняет оба print внутри неё, затем продолжает программу со строки после вызова. В вызове нет слова def и двоеточия, но скобки нужны.

Вызвать функцию можно несколько раз. При каждом вызове её действия выполняются заново. Внутри функции может быть и одно действие, и несколько.

Переделай программу. В начале определи свою функцию, которая выводит правильное предложение **«Гарри, Рон и Гермиона закатили глаза»**, а следующей строкой — три звёздочки подряд, без пробелов. Кавычки выводить не нужно. Имя функции придумай сам, используя латинские буквы.

<!-- section: execution -->
## Когда выполняются строки функции

Мы уже использовали определения и вызовы. Теперь подробно проследим за порядком выполнения: почему Python не начинает сразу со строк внутри функции?

> [!EXAMPLE]
> **Пример:** определение записано первым, но первым выводится число 1.
>
> ```python
> def show_code():
>     print(6)
>     print(2)
>
> print(1)
> show_code()
> print(3)
> ```
>
> ```output
> 1
> 6
> 2
> 3
> ```
>
> show_code означает «показать код». При определении функции Python запоминает её действия, но не выводит числа 6 и 2. Они появляются только при вызове show_code().

Вот что происходит:

1. Python определяет show_code. Строки внутри пока не выполняются.
2. Выполняет print(1).
3. Встречает вызов show_code() и выполняет тело функции: сначала print(6), затем print(2).
4. Закончив функцию, переходит к строке после вызова — print(3).

Если убрать строку show_code(), числа 6 и 2 вообще не появятся. Одного определения недостаточно.

Чтобы вызвать свою функцию, Python должен уже знать её определение. Пока будем записывать определения в начале программы, а вызовы — ниже.

## Что появится первым?

Прочитай программу, пока не запускаешь её. sun означает «солнце», moon — «луна».

```python
def sun():
    print("Солнце")

def moon():
    print("Луна")

moon()
print("Земля")
sun()
```

В каком порядке появятся слова? Выбери ответ. В каждом варианте слова перечислены в порядке отдельных строк вывода.

<!-- section: indentation -->
## Какие строки относятся к функции

Отступ нужен не для красоты. По нему Python определяет, какие действия выполнять при вызове функции.

> [!EXAMPLE]
> **Пример:** сообщение вне функции появляется один раз, а сообщение внутри — при каждом вызове.
>
> ```python
> def say_goodbye():
>     print("До встречи!")
>
> print("Программа запущена")
> say_goodbye()
> say_goodbye()
> ```
>
> ```output
> Программа запущена
> До встречи!
> До встречи!
> ```
>
> say_goodbye означает «попрощаться». Внутри функции только строка с сообщением «До встречи!»: у неё есть отступ. Строка print("Программа запущена") начинается от левого края. Она не относится к функции и выполняется до обоих вызовов.

Два вызова say_goodbye() тоже начинаются от левого края. Это отдельные действия программы, а не часть определения.

Все строки одного тела функции начинай с одинакового отступа — четырёх пробелов. Пустая строка сама по себе функцию не заканчивает: важно, с каким отступом записаны следующие действия.

## Почему билет неполный?

Функция show_ticket — «показать билет» — должна выводить две строки: **«Билет»** и **«Место 8»**. Но программа работает неправильно:

```python
def show_ticket():
    print("Билет")
print("Место 8")

show_ticket()
show_ticket()
```

Нужно получить два полных билета:

```output
Билет
Место 8
Билет
Место 8
```

Исправь программу, изменив только отступы. Не добавляй новые строки и не меняй порядок существующих. Оба вызова show_ticket должны остаться.

## Функция может вызывать другую функцию

Внутри своей функции можно вызывать не только print, но и другие написанные тобой функции.

Например, запишем ритм словами. Программа будет печатать «Топ» и «Хлоп», а не воспроизводить звуки.

> [!EXAMPLE]
> **Пример:** функция song вызывает chorus два раза.
>
> ```python
> def chorus():
>     print("Топ")
>     print("Хлоп")
>
> def song():
>     print("Начало")
>     chorus()
>     chorus()
>     print("Конец")
>
> song()
> ```
>
> ```output
> Начало
> Топ
> Хлоп
> Топ
> Хлоп
> Конец
> ```
>
> chorus означает «припев», song — «песня». Сначала Python определяет обе функции. Затем строка song() запускает действия песни.

Внутри song сначала выводится «Начало». Следующая строка вызывает chorus: выполняются два его действия. После этого Python продолжает song со следующей строки — ещё одного вызова chorus().

Когда заканчивается вторая пара действий, выводится «Конец». Так из нескольких небольших функций можно собрать более длинную последовательность действий.

## Сколько раз напечатано «Тук»?

В программе есть две функции. pair означает «пара», signal — «сигнал».

```python
def pair():
    print("Тук")
    print("Тук")

def signal():
    pair()
    pair()

signal()
pair()
```

## Нарисуй окно

Нарисуем окно с четырьмя стёклами с помощью обычного текста.

Напиши функцию draw_window — «нарисовать окно». Она должна выводить такой рисунок:

```output
+---+---+
|   |   |
|   |   |
+---+---+
|   |   |
|   |   |
+---+---+
```

Сам реши, какие повторяющиеся части рисунка удобно описать отдельными функциями. Придумай им имена и используй их внутри draw_window. Повторяющиеся части должны выводиться повторными вызовами функций, а не копиями print.

Между соседними стёклами должна быть одна общая граница, как на рисунке. Символы +, - и | здесь — обычный текст: записывай их внутри кавычек. Между соседними вертикальными линиями находятся три пробела.

Всю программу, включая определения функций, напиши самостоятельно. После всех определений один раз вызови draw_window(). Этот вызов должен вывести всё окно. Другие сообщения не добавляй.

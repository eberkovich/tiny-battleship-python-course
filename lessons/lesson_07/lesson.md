# Текст в программе

Текстовое значение называется строкой. Чтобы Python отличил текст от имени
переменной, его заключают в кавычки:

```python
message = "Корабли готовы"
print(message)
```

Переменная `message` хранит всю строку между кавычками. После запуска появится
`Корабли готовы`. Строку присваивания можно прочитать так: «сохрани текст
Корабли готовы под именем message». Python сохраняет сам текст без кавычек.
Открывающая и закрывающая кавычки должны быть одинаковыми; иначе Python не
понимает, где текст заканчивается.

# Кнопка перед боем

После расстановки кораблей программа должна дождаться игрока. Команда
`wait_for_button` показывает сообщение и кнопку, а затем ждёт нажатия:

```python
wait_for_button(message, label)
```

Аргументы:

- `message` — текст сообщения;
- `label` — текст на кнопке.

Пример:

```python
wait_for_button("Проверка закончена", "Продолжить")
```

На экране появится сообщение **«Проверка закончена»** и кнопка
**«Продолжить»**. Следующая команда программы выполнится только после нажатия.
Оба аргумента могут быть готовым текстом в кавычках или переменными, которые
уже хранят строки.

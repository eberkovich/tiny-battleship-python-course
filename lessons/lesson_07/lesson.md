# Текст в программе

Игра должна сообщать человеку, что происходит и что делать дальше. Для этого
программе нужно хранить не только числа и адреса, но и текст.

Текстовое значение в Python называется строкой. Строки используют для
сообщений, подписей и других слов, которые программа должна сохранить или
показать. Чтобы Python отличил текст от имени переменной, его заключают в
кавычки.

> [!EXAMPLE]
> **Пример:** сохраним текст под именем `message`, а затем выведем его.
>
> ```python
> message = "Корабли готовы"
> print(message)
> ```
>
> Переменная `message` хранит всю строку между кавычками. После запуска появится
> `Корабли готовы`. Python сохраняет сам текст без кавычек.

Первую строку примера можно прочитать так: «сохрани текст Корабли готовы под
именем message». Открывающая и закрывающая кавычки должны быть одинаковыми;
иначе Python не понимает, где текст заканчивается.

> [!EXAMPLE]
> **Пример:** если текст не понадобится позже, его можно сразу передать функции
> `print`.
>
> ```python
> print("Проверка готова")
> ```
>
> Python узнает строку по кавычкам и покажет `Проверка готова`.

# Диалог перед боем

После расстановки кораблей программа должна дождаться игрока. Диалог — это
небольшое окно поверх игры. Команда `show_message` показывает диалог с
сообщением и ждёт нажатия кнопки:

```python
show_message(message, label)
```

Аргументы:

- `message` — текст сообщения;
- `label` — текст на кнопке.

> [!EXAMPLE]
> **Пример:** покажем диалог о завершённой проверке.
>
> ```python
> show_message("Проверка закончена", "Продолжить")
> ```
>
> В диалоге появятся сообщение **«Проверка закончена»** и кнопка
> **«Продолжить»**. Следующая команда программы выполнится только после нажатия.
Оба аргумента могут быть готовым текстом в кавычках или переменными, которые
уже хранят строки.

Так программа управляет порядком шагов: сначала показывает результат, затем
ждёт решение человека и только после него продолжает работу.

## Задача со звёздочкой

Сделай обратный отсчёт перед боем. Собери в список четыре сообщения:
**«Три»**, **«Два»**, **«Один»**, **«Огонь!»**. По очереди показывай каждое сообщение в
диалоге с помощью `show_message`. На кнопке должно быть написано **«Дальше»**.

Используй один цикл и напиши `show_message` внутри него один раз. Четыре
одинаковых вызова подряд не подходят.

> [!RECAP]
> На всякий случай: запись `for value in values:` по очереди берёт значения
> списка, а команда с отступом выполняется для каждого из них.

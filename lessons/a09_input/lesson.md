# От текста к числам

<!-- section: text_or_number -->
## Похожая запись — разные значения

Человек вводит «12», но input получает **текст**, а не число. Текст может содержать цифры, однако для вычислений нужно числовое значение.

В коде **"12"** — текст: кавычки входят в его запись. **12** без кавычек — целое число. При выводе кавычки не показываются, поэтому на экране оба значения выглядят одинаково. Разница важна, когда мы хотим что-нибудь вычислить.

> [!EXAMPLE]
> **Пример:** две записи дают одинаковый вывод, но вычитать можно из числа.
>
> ```python
> label = "12"
> amount = 12
> print(label)
> print(amount)
> print(amount - 2)
> ```
>
> ```output
> 12
> 12
> 10
> ```
>
> label («надпись») хранит текст, amount («количество») — число. Последняя строка вычисляет 12 - 2. Если в ней написать label - 2, программа остановится с ошибкой: из текста нельзя вычесть число.

Текст и целое число — два **типа значений**. Тип определяет, какие действия можно выполнять со значением. Пока нам достаточно этих двух типов: текст для слов и целые числа для изученных вычислений.

## Как получить число из текста

Функция **int(value)** преобразует подходящий текст в целое число. value обозначает переданное значение. Например, int("12") даёт число 12, с которым можно считать.

> [!EXAMPLE]
> **Пример:** пользователь вводит количество жетонов. Программа считает, сколько останется после траты.
>
> ```python
> print("Сколько у тебя жетонов?")
> answer = input()
> tokens = int(answer)
> print(tokens - 4)
> ```
>
> ```input
> 17
> ```
>
> ```output
> Сколько у тебя жетонов?
> 13
> ```
>
> После input в answer («ответ») хранится текст "17". int читает его и даёт целое число 17; присваивание сохраняет это число в tokens («жетоны»). Последняя строка вычитает 4 из числа и выводит 13.

Действия идут по порядку: **получить текст → преобразовать в число → вычислить**. Пока записывай их отдельными строками, чтобы было видно, какое значение используется на каждом шаге.

<!-- section: retain_conversion -->
## Сохраняем преобразованное значение

int даёт новое числовое значение, но **сам не меняет переменную**, которую мы ему передали. Если число понадобится дальше, его нужно сохранить присваиванием.

> [!EXAMPLE]
> **Пример:** сохраняем число отдельно, а исходный ответ оставляем текстом.
>
> ```python
> answer = "24"
> number = int(answer)
> number = number + 6
> print(answer)
> print(number)
> ```
>
> ```output
> 24
> 30
> ```
>
> answer остаётся текстом "24". Число 24 сохраняется в number, затем увеличивается до 30. Изменение number не меняет answer. Вызов int(answer) без присваивания вычислил бы число, но не сохранил бы его ни в одной из этих переменных.

Можно сохранить преобразованное число и под прежним именем: answer = int(answer). Сначала int прочитает старый текст справа, затем присваивание заменит значение answer числом. Выбирай разные имена, когда нужны оба значения, и одно имя, когда исходный текст больше не нужен.

## Почему вычитание не работает?

Программа спрашивает, сколько листов бумаги было в пачке. Пять листов израсходовали; нужно вывести оставшееся количество. Но программа останавливается с ошибкой:

```python
print("Сколько листов было в пачке?")
sheets = input()
int(sheets)
print(sheets - 5)
```

Исправь её так, чтобы вычитание выполнялось с целым числом. Вопрос, расход пяти листов и порядок действий оставь прежними. После ответа выведи одно число на одной строке, без подписи.

Человек вводит целое количество не меньше 5. Программа должна вычислять остаток из введённого количества, а не печатать заранее известное число.

## Что можно преобразовать

Для наших задач вводи целое число цифрами: например, **27**, а не «двадцать семь». int понимает такую числовую запись, но не произвольное слово.

> [!EXAMPLE]
> **Пример:** преобразуем текст с целым числом.
>
> ```python
> answer = "27"
> number = int(answer)
> print(number)
> ```
>
> ```output
> 27
> ```
>
> В answer текст, а в number целое число. Если заменить "27" на "кот", int не сможет получить число и программа остановится с ошибкой. Это не значит, что input сломан: ответ не подходит для выбранного преобразования.

В следующих заданиях вводи только подходящие целые числа. Как проверять ответы и просить ввести их снова, изучим позже. Сейчас сосредоточимся на вычислениях.

## Угадай задуманное число

Сделай программу для числового фокуса. Человек **тайно задумывает положительное целое число**, прибавляет к нему 4, удваивает результат и вычитает 7. Программе он сообщает **только последнее полученное число**, а не задуманное.

Твоя программа должна получить этот ответ с помощью input, преобразовать его в число и вычислить, **какое число было задумано**. После ответа выведи только задуманное число на одной строке.

Подбери вычисление сам. Не спрашивай исходное число и не записывай в код готовый ответ. Перед запуском проведи фокус на бумаге с любым положительным целым числом, затем введи последний результат. Повтори с другим исходным числом: код менять не надо.

## Куры и овцы

На ферме живут только **куры и овцы**. У каждой курицы 2 ноги, у каждой овцы 4. Известно общее количество животных и общее количество ног. Нужно выяснить, сколько на ферме кур и сколько овец.

Напиши программу, которая получает **два целых числа**: сначала количество животных, затем количество ног. Преобразуй оба ответа в числа. Выведи два количества на отдельных строках: **сначала кур, затем овец**, без подписей.

Для проверки вручную можно взять 8 животных и 22 ноги. Это только данные для одного запуска, не числа для записи в код: программа должна работать и с другими подходящими ответами. Животных не меньше одного; ответы всегда соответствуют возможному количеству кур и овец. Проверять их правильность не нужно.

Сам придумай, как определить оба количества. На ферме могут быть только куры или только овцы: тогда количество другого вида равно 0. Если трудно начать, нарисуй животных или воспользуйся подсказкой.

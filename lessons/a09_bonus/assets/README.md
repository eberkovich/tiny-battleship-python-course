# Capstone artwork and provenance

Original static illustrations generated with the built-in image-generation tool.
Only the selected PNGs are shipped; rejected variants remain outside the project.
All labels, prices, coin equivalences, and the 9¾ number are application text.
The twins revision uses plain rumpled clothes and mischievous expressions instead
of ornate fashion-model styling. The original glamorous variant is not shipped.

Teaching starting point: [Code Avengers Python 1, sections 7.3–7.4](https://assets.codeavengers.com/file/cloud/python/1/lesson-plans/ca-py1-instructions.pdf).
The three-product magical setting and payment/change extension are adaptations;
prices are fictional. Character/product and currency references are the official
[shop description](https://www.harrypotter.com/fact-file/locations/weasleys-wizard-wheezes)
and [wizarding money](https://www.harrypotter.com/fact-file/objects/wizarding-money).
These images are original illustrations, not film stills or scanned artwork.

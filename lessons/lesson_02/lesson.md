# Как увидеть значение

Иногда программе нужно показать человеку результат: число, текст или другое
значение. Для этого в Python есть функция `print`. Её название по-английски
означает «напечатать».

Функция записывается так:

```python
print(value)
```

Аргумент:

- `value` — значение, которое нужно показать.

Пример:

```python
print(7)
```

Эту строку можно прочитать так: «покажи значение 7». Python сначала берёт
значение внутри круглых скобок, а затем показывает его. После запуска программа
покажет число `7`.

`print` используют, чтобы показать результат, вывести сообщение или проверить,
какое значение сейчас хранит программа. Если забыть круглые скобки, вызов
функции записан неправильно.

# Имя для значения

Во время игры программа должна помнить координаты и количество кораблей, а
позже использовать или изменять их. Для этого значение можно сохранить под
понятным именем:

```python
ships = 3
```

Знак `=` означает: сохранить значение справа под именем слева. Такое имя
называется переменной. Позже вместо числа можно написать имя:

```python
print(ships)
```

Python найдёт сохранённое значение и покажет `3`. Значение переменной можно
заменить новой командой с `=`. Строку `ships = 3` можно прочитать так:
«сохрани число 3 под именем ships». Python сначала вычисляет значение справа,
а затем связывает его с именем слева.

Переменная — это способ помнить информацию во время работы программы. Так
хранят не только корабли: под именами можно сохранять результат вычисления,
настройку или любое значение, которое понадобится следующим шагам программы.

Имя нужно каждый раз писать одинаково. `ships` и `ship` — два разных имени;
если значение сохранено только в `ships`, Python не знает, что означает `ship`.

Строка, которая начинается со знака `#`, — это комментарий. Она объясняет код
человеку, а Python её не выполняет:

```python
# Количество готовых кораблей.
ships = 3
```

# Счётчик кораблей

Команда `show_ship_count` показывает возле поля, сколько кораблей осталось:

```python
show_ship_count(board, count)
```

Аргументы:

- `board` — игровое поле. Возможные значения:
  - `PLAYER` — твоё поле;
  - `ENEMY` — поле противника;
- `count` — целое неотрицательное количество кораблей.

Пример — показать возле поля противника число из переменной:

```python
enemy_ships = 4
show_ship_count(ENEMY, enemy_ships)
```

После запуска возле поля противника появится счётчик `4`. Повторный вызов
команды обновляет число.

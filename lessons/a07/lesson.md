# Изменяем значение переменной

<!-- section: new_value -->
## То же имя, новое значение

В прошлом уроке переменная помогала запомнить число и использовать его несколько раз. Но во время работы программы число может измениться: игрок получает очки, тратит монеты или теряет жизнь.

Чтобы следить за текущим количеством, можно сохранять новое число в той же переменной. Для этого снова напиши её имя слева от =.

> [!EXAMPLE]
> **Пример:** сначала у игрока 12 монет, затем количество меняется на 20.
>
> ```python
> coins = 12
> print(coins)
> coins = 20
> print(coins)
> ```
>
> ```output
> 12
> 20
> ```
>
> coins означает «монеты». После первой строки coins → 12. Третья строка заменяет значение: теперь coins → 20. Каждый print показывает число, связанное с именем в момент вызова.

Имя остаётся прежним, а значение меняется. Под именем coins теперь хранится 20, не два числа сразу. Но первая строка вывода уже появилась: новое присваивание её не стирает.

Оба присваивания выполняются за один запуск программы. Не нужно менять файл между ними: Python дойдёт до каждой строки по порядку.

<!-- section: calculate_update -->
## Прибавляем к текущему значению

В предыдущем примере мы уже знали новое количество монет. Но чаще известен не итог, а изменение: например, игрок заработал ещё 6 очков. Нужно взять текущее количество, прибавить выигрыш и сохранить результат.

> [!EXAMPLE]
> **Пример:** игрок получает 6 очков, затем теряет 4.
>
> ```python
> points = 18
> points = points + 6
> print(points)
> points = points - 4
> print(points)
> ```
>
> ```output
> 24
> 20
> ```
>
> points означает «очки». Во второй строке Python сначала берёт текущее значение points: 18. Вычисляет 18 + 6, получает 24 и сохраняет его под именем points. В четвёртой строке он уже берёт 24, вычитает 4 и сохраняет 20.

В строке points = points + 6 одно имя встречается дважды. **Справа** Python читает прежнее значение и вычисляет результат. **Слева** указано имя, под которым нужно сохранить этот результат. Замена происходит после вычисления, не раньше.

По тому же правилу можно вычитать, умножать или делить нацело. Правая часть вычисляется обычным способом; присваивание сохраняет полученное число.

## Награда и покупки

У игрока **136 монет**. Он выполняет **три задания** и за каждое получает **27 монет**. Затем покупает **два зелья по 49 монет**.

В программе уже сохранено и выведено начальное количество монет в переменной coins («монеты»). Допиши программу: сначала увеличь coins на всю награду и выведи новое количество. Затем уменьши coins на стоимость обеих покупок и снова выведи количество.

Всего должно появиться **три числа**, каждое на своей строке: до награды, после награды, после покупок. Используй текущее значение coins при каждом изменении. Не записывай готовые итоги вместо вычислений.

> [!NOTE]
> Открой редактор → выполни задание → сохрани изменения → нажми **«Запустить»**.

<!-- section: print_or_save -->
## Вывести — не значит сохранить

print показывает переданное ему значение. Если передать вычисление, он покажет результат, но не заменит значение переменной.

> [!EXAMPLE]
> **Пример:** показываем, сколько было бы очков после прибавления, но не сохраняем прибавление.
>
> ```python
> points = 30
> print(points + 8)
> print(points)
> ```
>
> ```output
> 38
> 30
> ```
>
> Первый print вычисляет 30 + 8 и показывает 38. Присваивания нет, поэтому points по-прежнему связано с числом 30. Второй print показывает именно его.

Чтобы сохранить новое количество, нужно присваивание. Вывод — отдельное действие.

> [!EXAMPLE]
> **Пример:** сохраняем прибавление, затем показываем новое количество очков.
>
> ```python
> points = 30
> points = points + 8
> print(points)
> ```
>
> ```output
> 38
> ```
>
> Вторая строка сохраняет 38 в points. Теперь любое следующее чтение points будет использовать это число, пока другое присваивание не заменит его.

## Куда пропала покупка?

У игрока **80 монет**. Он тратит **25 монет**, а затем находит ещё **10**. Программа должна показать количество монет после траты и после находки:

```python
coins = 80
print(coins - 25)
coins = coins + 10
print(coins)
```

Первое число получается правильным, а второе — нет. Найди и исправь ошибку. Можно менять или добавлять строки, но начальное количество, трата и находка должны остаться прежними.

После каждого события новое количество должно сохраняться в coins («монеты»). Выведи два количества на отдельных строках, без слов. Готовые ответы вместо вычислений не записывай.

> [!NOTE]
> Открой редактор → выполни задание → сохрани изменения → нажми **«Запустить»**.

## Размени деньги

Нужно разменять **137 рублей** монетами по **10, 5 и 1 рублю**. Монет каждого вида сколько угодно. Собери ровно нужную сумму и используй **как можно меньше монет**.

В программе уже есть amount = 137. amount означает «сумма». Используй эту переменную для суммы, которую ещё осталось разменять, и обновляй её по мере размена. Для количества монет можно придумать другие имена.

Выведи три числа на отдельных строках: сколько нужно монет по 10 рублей, затем по 5, затем по 1. Если монеты какого-то вида не нужны, выведи 0 на их строке.

Не записывай готовые количества монет. Все количества должны вычисляться из amount. Если изменить только начальную сумму, программа должна уметь разменять и её. Для проверки кнопкой «Запустить» оставь начальную сумму 137.

> [!RECAP]
> На всякий случай: деление нацело // считает только целые группы. Чтобы узнать, сколько всего предметов в этих группах, умножь количество групп на размер одной. Вычти это количество из исходного — получишь остаток.

> [!NOTE]
> Открой редактор → выполни задание → сохрани изменения → нажми **«Запустить»**.

<!-- section: keep_number -->
## Сохраняем прежнее число

Иногда нужно изменить число, но при этом помнить, каким оно было раньше. Например, чтобы сравнить очки до и после раунда. До изменения можно сохранить текущее число под другим именем.

> [!EXAMPLE]
> **Пример:** сохраняем очки до раунда и отдельно увеличиваем текущие очки.
>
> ```python
> points = 14
> before = points
> points = points + 6
> print(before)
> print(points)
> ```
>
> ```output
> 14
> 20
> ```
>
> before означает «до». Во второй строке Python читает points, получает число 14 и сохраняет его под именем before. После этого points → 14 и before → 14. Третья строка меняет только points: теперь points → 20, а before → 14.

В before сохранено число, которое было в points **в момент присваивания**. Более позднее изменение points не меняет это сохранённое число.

## Что сохранили?

Прочитай программу, пока не запускаешь её. saved означает «сохранённое»:

```python
number = 18
saved = number
number = number + 7
print(number)
print(saved + 2)
```

Какие два числа она выведет и в каком порядке? В каждом варианте числа означают отдельные строки вывода.

## Поменяй значения местами

В программе записаны два числа:

```python
left = 137
right = 284
```

left означает «левый», right — «правый». Допиши программу так, чтобы значения **поменялись местами**: в left оказалось прежнее значение right, а в right — прежнее значение left. Затем выведи left и right, каждое на своей строке, в этом порядке.

Начальные строки не меняй и не используй числа 137 и 284 повторно. Программа должна брать значения из переменных, а не подставлять известные ответы. Если заменить только начальные числа, обмен тоже должен работать. Для проверки кнопкой «Запустить» оставь исходные числа.

Можно создавать другие переменные. Используй обычные присваивания: одно имя слева от = в каждой строке. Подумай, какое число может потеряться при замене и как этого избежать.

> [!NOTE]
> Открой редактор → выполни задание → сохрани изменения → нажми **«Запустить»**.

## Итоги урока

Ты потренировался изменять значение переменной во время работы программы. Если справа от = есть имя переменной, Python сначала читает её текущее значение и вычисляет результат, а затем сохраняет результат под именем слева.

В задаче про покупку ты проверял разницу между выводом и сохранением: print может показать новое количество, не изменив coins. В размене ты выбирал монеты и уменьшал сумму, которую осталось разменять.

Ещё ты сохранял прежнее число под другим именем и решал задачу об обмене двух значений. Объясни, зачем при таком обмене может понадобиться ещё одна переменная.

# Выполняем строки по порядку

<!-- section: order -->
## Сначала верхняя строка

Ты уже умеешь показывать сообщение с помощью print. Чтобы показать несколько сообщений, можно записать несколько вызовов.

В такой программе Python выполняет вызовы **сверху вниз**: сначала верхний, затем следующий. Каждый print выводит сообщение на новой строке.

> [!EXAMPLE]
> **Пример:** два вызова выполняются по очереди.
>
> ```python
> print("Открыть ворота")
> print("Войти")
> ```
>
> ```output
> Открыть ворота
> Войти
> ```
>
> Сначала Python выполняет верхний вызов, затем нижний. Сообщения появляются в том же порядке, в каком записаны вызовы.

Каждый вызов здесь выполняется один раз. После второго программа заканчивается. Чтобы сообщения появились снова, эту программу нужно запустить ещё раз.

<!-- section: empty_lines -->
## Строки без действий

В программе можно оставить пустую строку, чтобы отделить одну часть от другой. Python её пропускает: она не выводит сообщение и не создаёт паузу.

Как ты узнал в первом уроке, комментарии тоже не выполняются. Если написать # перед вызовом print, вся строка станет комментарием.

> [!EXAMPLE]
> **Пример:** между двумя действиями есть пустая строка и комментарий.
>
> ```python
> print("Утро")
>
> # print("День")
> print("Вечер")
> ```
>
> ```output
> Утро
> Вечер
> ```
>
> Python выполняет print("Утро"), пропускает пустую строку и комментарий, затем выполняет print("Вечер"). Поэтому в выводе два сообщения без пустой строки между ними.

Число строк в файле и число сообщений могут отличаться. Здесь четыре строки кода, но выполняются только два вызова print.

<!-- section: q_order -->
## Два числа или три?

Прочитай программу сверху вниз, пока не запускаешь её:

```python
print(2)

# print(7)
print(5)
```

Что она покажет? В каждом варианте числа перечислены в порядке вывода; каждое появится на отдельной строке.

## Восстанови порядок финиша

Четверо детей закончили забег в разное время. У Пети номер 1, у Лены — 2, у Вани — 3, у Маши — 4.

У нас есть три подсказки:

- Петя финишировал раньше Лены, но не обязательно прямо перед ней.
- Ваня финишировал сразу после Лены: между ними никого нет.
- Маша не была ни первой, ни последней.

Определи **весь порядок финиша**. Затем напиши программу, которая показывает номера участников в этом порядке, каждый на отдельной строке. Должны появиться четыре числа и ничего больше.

Реши задачу сам или на бумаге. Программа только сообщает найденный тобой порядок; искать его вместо тебя ей пока не нужно.

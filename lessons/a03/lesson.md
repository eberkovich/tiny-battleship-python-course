# Выполняем строки по порядку

<!-- section: order -->
## Сначала верхняя строка

Один вызов print показывает одно значение. А что произойдёт, если записать несколько вызовов?

Python выполняет их **сверху вниз**: сначала первую строку, потом следующую. Каждый новый print показывает результат на новой строке.

> [!EXAMPLE]
> **Пример:** два вызова выполняются по очереди.
>
> ```python
> print("Открыть ворота")
> print("Войти")
> ```
>
> Сначала появится Открыть ворота, а под ним — Войти. Python не меняет порядок, даже если другой порядок кажется человеку удобнее.

Назад к первой строке Python сам не возвращается. Когда все инструкции выполнены, эта программа заканчивается.

<!-- section: empty_lines -->
## Строки без действий

Пустые строки помогают разделить программу на части. Они не показывают результат и не заставляют Python ждать.

Комментарии тоже не выполняются. Знак # может стоять даже перед текстом, похожим на вызов: эта строка всё равно остаётся комментарием.

> [!EXAMPLE]
> **Пример:** между двумя действиями есть пустая строка и комментарий.
>
> ```python
> print("Утро")
>
> # print("День")
> print("Вечер")
> ```
>
> Первая строка показывает Утро. Пустая строка ничего не делает. Строка с # ничего не показывает. Последний вызов показывает Вечер — сразу на следующей строке результата.

Считай выполненные вызовы, а не все строки в файле: здесь сообщений два, не четыре.

<!-- section: q_order -->
## Два числа или три?

Прочитай программу сверху вниз, пока не запускаешь её:

```python
print(2)

# print(7)
print(5)
```

Что она покажет? В каждом варианте числа перечислены в порядке вывода; каждое появится на отдельной строке.

## Восстанови финиш

Четверо детей закончили забег в разное время. У Пети номер 1, у Лены — 2, у Вани — 3, у Маши — 4.

У нас есть три подсказки:

- Петя финишировал раньше Лены, но не обязательно прямо перед ней.
- Ваня финишировал сразу после Лены: между ними никого нет.
- Маша не была ни первой, ни последней.

Определи **весь порядок финиша**. Затем напиши программу, которая показывает номера участников в этом порядке, каждый на отдельной строке. Должны появиться четыре числа и ничего больше.

Реши задачу сам или на бумаге. Программа только сообщает найденный тобой порядок; искать его вместо тебя ей пока не нужно.

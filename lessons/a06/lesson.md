## Зачем нужны переменные

Билет в музей стоит **135 рублей**. Нужно узнать стоимость двух, пяти и восьми билетов. Ты уже умеешь написать такую программу:

> [!EXAMPLE]
> **Пример:** одна и та же цена участвует в трёх вычислениях.
>
> ```python
> print(135 * 2)
> print(135 * 5)
> print(135 * 8)
> ```
>
> ```output
> 270
> 675
> 1080
> ```
>
> Каждый вызов print показывает стоимость нужного количества билетов. Цена 135 написана в каждой строке.

А если цена стала **170 рублей**? Придётся заменить 135 в трёх местах. Если забыть одну строку, часть ответов останется со старой ценой. Можно сделать удобнее: записать цену один раз и дальше обращаться к ней по имени.

**Переменная** — это имя, с которым связано значение. Запись **price = 135** создаёт переменную price («цена») и сохраняет в ней число 135. Такая запись называется **присваиванием**: слева от **=** стоит имя, справа — значение, которое нужно сохранить. Здесь = означает «сохрани под этим именем».

Когда Python встречает price в вычислении, он берёт сохранённое значение — 135. Поэтому price * 2 даст тот же результат, что и 135 * 2.

> [!EXAMPLE]
> **Пример:** сохраняем цену один раз и используем её три раза.
>
> ```python
> price = 135
> print(price * 2)
> print(price * 5)
> print(price * 8)
> ```
>
> ```output
> 270
> 675
> 1080
> ```
>
> Первая строка связывает имя price с числом 135. В следующих строках Python находит число по этому имени и использует его в вычислениях. Получаются те же ответы, но цена записана только в одном месте.

Теперь для новой цены достаточно изменить первую строку на **price = 170** и запустить программу заново. Все три вычисления будут использовать 170. Переменные помогают не только запоминать числа, но и использовать одни данные в нескольких действиях.

Связь имени со значением можно показать стрелкой: **price → 135**. Это пояснение, а не строка Python.

Само присваивание ничего не выводит. Чтобы человек увидел значение, нужен print. До строки price = 135 переменной price в этой программе ещё нет: сначала создай её, затем используй.

Имя без кавычек и текст в кавычках — разные вещи. Посмотрим на переменную stars — по-английски «звёзды».

> [!EXAMPLE]
> **Пример:** можно показать и само имя, и значение переменной.
>
> ```python
> stars = 37
> print("stars")
> print(stars)
> ```
>
> ```output
> stars
> 37
> ```
>
> Кавычки в первом print обозначают текст. Во втором кавычек нет: Python ищет переменную stars и берёт её значение. Кавычки не нужны ни у имени слева от =, ни у числа 37 справа.

## Как писать имена

Имя должно помогать понять, какое значение хранится в переменной. tickets означает «билеты», а ticket_price — «цена билета». Между словами в таком имени стоит **подчёркивание _**, а не пробел: всё имя пишется слитно.

> [!EXAMPLE]
> **Пример:** у двух переменных разные имена и разные значения.
>
> ```python
> tickets = 3
> ticket_price = 40
> print(tickets)
> print(ticket_price)
> ```
>
> ```output
> 3
> 40
> ```
>
> Имя tickets связано с числом 3, а ticket_price — с числом 40. Чтобы получить нужное значение, Python ищет именно то имя, которое написано в print.

Для наших имён используй английские буквы, цифры и подчёркивание. Начинай с буквы; пробелы внутри имени не ставь. Не называй переменную print: это имя уже нужно для знакомой функции.

**Большая и маленькая буквы различаются.** tickets и Tickets — два разных имени. Если создать tickets, а затем попросить Tickets, Python сообщит, что такого имени нет. Написание имени должно совпадать во всех строках, где нужна одна и та же переменная.

## Считаем со значениями переменных

В выражении можно использовать имя переменной вместо числа. Python сначала находит её значение, затем выполняет вычисление.

> [!EXAMPLE]
> **Пример:** вычисление в print не меняет сохранённое значение.
>
> ```python
> length = 9
> print(length + 2)
> print(length)
> ```
>
> ```output
> 11
> 9
> ```
>
> length означает «длина». В выражении length + 2 Python использует число 9 и получает 11. Это результат сложения, но переменная length по-прежнему связана с числом 9. Последний print показывает именно его.

Иногда ответ одного вычисления нужен в нескольких следующих. Вместо того чтобы заново писать всё выражение, можно сохранить результат в переменной. Для этого запиши выражение справа от =.

За четырьмя столами сидят по шесть детей. Узнаем, сколько всего детей и сколько яблок нужно, если каждому дать по два.

> [!EXAMPLE]
> **Пример:** считаем детей один раз, затем используем полученное количество.
>
> ```python
> tables = 4
> per_table = 6
> children = tables * per_table
> print(children)
> print(children * 2)
> ```
>
> ```output
> 24
> 48
> ```
>
> tables означает «столы», per_table — «за одним столом», children — «дети». Третья строка сначала вычисляет 4 * 6, затем сохраняет результат 24 под именем children. Первый print показывает это количество, второй использует его для подсчёта яблок: 24 * 2 даёт 48.

Слева от = указывается одно имя, справа — число или выражение. Python сначала вычисляет правую часть и сохраняет её **результат**, а не запись вычисления.

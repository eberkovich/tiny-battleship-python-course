# Показываем текст и числа

<!-- section: print_text -->
## Показываем текст

Ты хочешь, чтобы программа показала сообщение. Для этого в Python есть функция **print**. Функция — команда с именем: чтобы выполнить её, пишут её имя и круглые скобки. Такую запись называют **вызовом функции**.

> [!EXAMPLE]
> **Пример:** покажем короткое сообщение.
>
> ```python
> print("Ура!")
> ```
>
> После запуска появится текст: Ура!

Вызов читается так: «print, покажи текст Ура!». print — имя функции. После него стоит открывающая скобка (, а в конце — закрывающая ).

Внутри скобок написано, **что показать**. Такое переданное значение называют **аргументом**. В этом примере аргумент — текст "Ура!".

Текст заключают в две прямые двойные кавычки: одну перед текстом, другую после. Они отмечают его начало и конец, но сами не появляются в результате.

> [!EXAMPLE]
> **Пример:** изменим только текст внутри кавычек.
>
> ```python
> print("Робот готов")
> ```
>
> Появится: Робот готов. Имя print, скобки и кавычки остались на своих местах.

В этом учебнике после запуска текст появится в отдельном блоке **«Результат программы»**. Он показывает, что вывела твоя программа, а не объяснение задания.

## Число или текст

print умеет показывать не только текст, но и числа. Число внутри скобок пишут **без кавычек**.

> [!EXAMPLE]
> **Пример:** покажем число.
>
> ```python
> print(6)
> ```
>
> Появится число 6.

Сравни: в print(6) передано число 6, а в print("шесть") — текст "шесть". Функция одна и та же, но значения разные.

> [!EXAMPLE]
> **Пример:** текст может совпадать с именем функции.
>
> ```python
> print("робот")
> ```
>
> Python показывает слово робот. Он не пытается выполнить слово внутри кавычек как команду.

Чтобы показать число, выбирай число без кавычек. Чтобы показать слово или сообщение, выбирай текст в кавычках.

<!-- section: q_print -->
## Что покажет print?

Посмотри на вызов:

```python
print("print")
```

Какой результат появится? Обрати внимание: одно print стоит перед скобкой, а другое — внутри кавычек.

<!-- section: argument -->
## Имя аргумента и его значение

В описании функции удобно дать имя месту, куда ты подставишь значение. Для print это место назовём **value** — по-английски «значение».

```text
print(value)
```

Это **схема для объяснения, а не готовая строка для запуска**. Здесь value — название аргумента в описании. Писать слово value в своей программе сейчас не нужно: вместо него выбирают настоящее значение.

> [!EXAMPLE]
> **Пример:** подставим число на место аргумента.
>
> ```python
> print(9)
> ```
>
> В схеме место называется value. В этом вызове ему соответствует значение 9. После запуска появится 9.

- print — имя функции; его не меняем.
- value — имя места для аргумента в описании, не ответ программы.
- 9 — настоящее значение, переданное в примере; его можно заменить другим числом.

> [!EXAMPLE]
> **Пример с текстом:**
>
> ```python
> print("Можно начинать")
> ```
>
> Здесь тому же месту value соответствует текст "Можно начинать". Появится: Можно начинать.

Каждой открывающей скобке нужна закрывающая. Если забыть её, Python не сможет прочитать вызов и сообщит об ошибке. Сначала исправь запись, а затем запусти программу снова.

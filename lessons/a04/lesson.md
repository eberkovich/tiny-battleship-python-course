# Числа и вычисления

## Python считает за тебя

Раньше ты находил ответ сам, а print показывал готовое число. Теперь вычисление можно поручить Python.

Запиши между скобками print числа и знак действия. Знак **+** означает сложение, а **-** — вычитание.

> [!EXAMPLE]
> **Пример:** Python складывает два числа и показывает результат.
>
> ```python
> print(28 + 16)
> ```
>
> ```output
> 44
> ```
>
> Сначала Python вычисляет 28 + 16. Получается число 44. Затем print выводит это число.

Запись с числами и знаками действий называют **выражением**. Здесь выражение — 28 + 16, а его значение — 44.

> [!EXAMPLE]
> **Пример:** в следующем вызове Python выполняет вычитание.
>
> ```python
> print(73 - 25)
> ```
>
> ```output
> 48
> ```
>
> Python вычитает 25 из 73 и передаёт полученное число функции print. Пробелы вокруг знака помогают читать запись; на результат они не влияют.

Если в выражении несколько сложений и вычитаний, Python выполняет их **слева направо**.

> [!EXAMPLE]
> **Пример:** вычитание и сложение выполняются по порядку.
>
> ```python
> print(30 - 8 + 2)
> ```
>
> ```output
> 24
> ```
>
> Сначала Python вычитает 8 из 30 и получает 22. Затем прибавляет 2. Он не складывает 8 и 2 перед вычитанием.

## Вычисление или текст

Чтобы Python выполнил вычисление, запиши числа и знаки действий без кавычек. Запись в кавычках — это текст: Python покажет его, но не выполнит записанное в нём вычисление.

> [!EXAMPLE]
> **Пример:** одинаковые знаки в кавычках и без них дают разный вывод.
>
> ```python
> print("17 + 8")
> print(17 + 8)
> ```
>
> ```output
> 17 + 8
> 25
> ```
>
> Первый вызов выводит текст. Во втором Python сначала складывает числа, а затем выводит результат.

## Число или запись?

Прочитай программу, пока не запускаешь её:

```python
print("240 + 36")
print(240 + 36)
```

Что она покажет? В каждом варианте указан сначала вывод верхнего вызова, затем нижнего; они появятся на отдельных строках.

<!-- section: multiplication -->
## Умножение

Если нужно сложить несколько одинаковых чисел, можно использовать умножение. В Python его записывают звёздочкой `*`, а не буквой x или знаком ×.

> [!EXAMPLE]
> **Пример:** две записи вычисляют одно и то же.
>
> ```python
> print(6 + 6 + 6 + 6 + 6)
> print(6 * 5)
> ```
>
> ```output
> 30
> 30
> ```
>
> В первой строке число 6 складывается пять раз. Во второй 6 умножается на 5. Результаты одинаковые, но запись с умножением короче.

Сейчас число 2473 складывается четыре раза. Измени программу: пусть она вычисляет сумму **девяти** таких чисел. Используй умножение вместо длинного сложения. Сохрани один вызов print и выведи только результат нового вычисления.

<!-- section: division -->
## Деление нацело

Знак **//** — две косые черты подряд — означает деление нацело. Число слева делят на число справа. При таком делении мы считаем только целые группы.

> [!EXAMPLE]
> **Пример:** делим 48 на 6 без остатка.
>
> ```python
> print(48 // 6)
> ```
>
> ```output
> 8
> ```
>
> В числе 48 ровно восемь шестёрок: 8 умножить на 6 — это 48.

> [!EXAMPLE]
> **Пример:** если взять 50 вместо 48, остаётся ещё 2.
>
> ```python
> print(50 // 6)
> ```
>
> ```output
> 8
> ```
>
> В 50 помещаются восемь целых шестёрок. Для девятой нужно 54. Результат деления нацело — количество целых групп: 8. Остаток 2 в этот результат не входит.

В этом уроке мы делим числа больше нуля, без дробей. В записи // два знака, но они обозначают одно действие. Делить на ноль нельзя.

<!-- section: order -->
## Порядок вычислений

В одном выражении можно записать несколько действий. Python выполняет **умножение и деление нацело раньше сложения и вычитания**.

> [!EXAMPLE]
> **Пример:** умножение выполняется раньше, хотя плюс записан слева от него.
>
> ```python
> print(8 + 3 * 4)
> ```
>
> ```output
> 20
> ```
>
> Сначала Python умножает 3 на 4: получается 12. Затем прибавляет 8. Он не складывает 8 и 3 перед умножением.

Если в выражении остались только сложение и вычитание, они выполняются слева направо. Умножение и деление нацело между собой тоже выполняются слева направо.

> [!EXAMPLE]
> **Пример:** сначала делим, затем умножаем.
>
> ```python
> print(42 // 3 * 2)
> ```
>
> ```output
> 28
> ```
>
> Деление и умножение здесь равноправны. Python идёт слева направо: 42 делит на 3, получает 14, затем умножает 14 на 2.

Числа в программе записывай без пробелов внутри: 2473, а не 2 473. Пробелы между числом и знаком действия ставить можно.

В этом курсе ты полностью создашь игру «Морской бой» с однопалубными

# Как устроена команда

Чтобы твоя программа узнала о вспомогательных командах, в начале каждой
программы уже есть строка:

```python
from battleship_ui import *
```

Она подключает вспомогательные команды к твоей программе. Эту строку изменять
не нужно.

---

Вспомогательные команды, которыми ты будешь пользоваться, — это функции Python.

У каждой функции есть имя. Чтобы выполнить функцию, напиши её имя и круглые
скобки. Такая запись называется вызовом функции.

Функции встречаются в самых разных программах. Они дают действию понятное имя,
чтобы его можно было выполнить тогда, когда оно понадобится. В этой игре
первыми такими действиями будут показ поля, корабля и выстрела.

Некоторым функциям нужна дополнительная информация. Например, команда показа
поля должна узнать, какое именно поле нужно показать. Эту информацию передают
внутри круглых скобок. Она называется аргументом.

У аргумента есть две разные части, которые важно не путать:

- **имя аргумента** встречается в описании команды и объясняет, какая
  информация нужна;
- **значение аргумента** записывается в вызове и сообщает, что именно нужно
  использовать сейчас.

Имя функции, круглые скобки и значение внутри образуют вызов функции.
Правила такой записи называются синтаксисом вызова.

---

Первая вспомогательная команда — `show_board`. Она показывает игровое поле.
В описании команды её записывают так:

```python
show_board(board)
```

Это ещё не готовый вызов, а подсказка о его устройстве. `show_board` — имя
функции, а `board` — имя аргумента. Оно означает «игровое поле» и показывает,
какое значение нужно поставить на это место. Само слово `board` не выбирает
конкретное поле.

Для аргумента с именем `board` подходят два значения:

- `PLAYER` — твоё поле;
- `ENEMY` — поле противника.

> [!EXAMPLE]
> **Пример:** передадим в аргумент с именем `board` значение `ENEMY`.
>
> ```python
> show_board(ENEMY)
> ```
>
> В этом вызове `show_board` — имя функции, а `ENEMY` — значение аргумента.
> Python передаст значение `ENEMY` на место с именем `board`, и функция поймёт,
> что нужно показать поле противника. После запуска появится пустое поле
> размером 10 на 10 клеток.

Имя аргумента `board` остаётся тем же в описании команды. Значение для него ты
выбираешь при каждом вызове в зависимости от нужного результата.

# Как Python читает код

Программа состоит из строк. В программах этого урока Python начинает с верхней
строки, выполняет её и переходит к следующей. Так он движется сверху вниз,
обрабатывая строки по одной.

> [!EXAMPLE]
> **Пример:** проследим, что Python сделает с тремя строками программы.
>
> ```python
> from battleship_ui import *
> # Следующая строка показывает поле.
> show_board(ENEMY)
> ```
>
> Сначала первая строка подключит вспомогательные команды. Вторая строка
> начинается со знака `#`, поэтому Python пропустит её. Затем третья строка
> покажет поле противника.

Строка, которая начинается со знака `#`, называется комментарием. Комментарий —
это подсказка для человека, который читает код. Python не выполняет комментарии,
а сразу переходит к следующей строке. Пустые строки тоже не выполняют действий:
они только помогают разделять код на понятные части.

Порядок строк важен. Сначала программа должна подключить вспомогательные
команды, и только после этого их можно вызывать.

Пиши свой код под комментарием. Сам комментарий можно оставить в файле.

# Координаты и корабли

Чтобы поставить корабль или показать выстрел в нужной клетке, программе нужен
её точный адрес. Способ задавать такие адреса называется системой координат.

Адрес каждой клетки состоит из двух чисел: `(x, y)`.

- `x` — номер столбца слева направо;
- `y` — номер строки сверху вниз;
- на поле 10 столбцов и 10 строк, поэтому `x` и `y` имеют значения от 1 до 10.

Первая координата всегда означает `x`, а вторая — `y`.

> [!EXAMPLE]
> **Пример:** адрес `(6, 3)` означает клетку в шестом столбце и третьей строке.
> Здесь порядок чисел задаёт сначала столбец, затем строку.

---

Теперь можно выбрать клетку для корабля. Команде `draw_deck` нужно передать
несколько аргументов. Их пишут внутри скобок по порядку и разделяют запятыми.

Команда `draw_deck` рисует одну палубу корабля:

```python
draw_deck(board, x, y, state)
```

Аргументы:

- `board` — игровое поле. Возможные значения:
  - `PLAYER` — твоё поле;
  - `ENEMY` — поле противника;
- `x` — номер столбца;
- `y` — номер строки;
- `state` — состояние палубы. Возможные значения:
  - `DECK_IDLE` — палуба не повреждена.

> [!EXAMPLE]
> **Пример:** нарисуем палубу на поле игрока в клетке `(5, 7)`.
>
> ```python
> draw_deck(PLAYER, 5, 7, DECK_IDLE)
> ```
>
> После запуска в клетке `(5, 7)` появится палуба корабля.

---

Команда `show_miss` показывает, что выстрел в выбранную клетку не попал в
корабль:

```python
show_miss(board, x, y)
```

Аргументы:

- `board` — игровое поле. Возможные значения:
  - `PLAYER` — твоё поле;
  - `ENEMY` — поле противника;
- `x` — номер столбца;
- `y` — номер строки.

> [!EXAMPLE]
> **Пример:** покажем промах на поле противника в клетке `(8, 6)`.
>
> ```python
> show_miss(ENEMY, 8, 6)
> ```
>
> После запуска в клетке `(8, 6)` появится промах.

## Задача со звёздочкой

На своём поле уже стоят три корабля в левой половине. Твоя задача — достроить
симметричный строй, добавив для каждого корабля зеркальную пару справа.

Зеркальная пара стоит на той же строке и на таком же расстоянии от правого края.

> [!EXAMPLE]
> **Пример:** если корабль стоит в клетке `(1, 4)`, его зеркальная пара находится
> в клетке `(10, 4)`.

Начальные корабли находятся в клетках `(2, 2)`, `(3, 5)` и `(4, 8)`. Добавь
для каждого из них зеркальный корабль в правой половине поля.

После запуска на поле должны быть шесть кораблей, расположенных симметрично.
Сам вычисли три недостающих адреса. Оба поля должны остаться на экране.

# Итоги урока

Python выполняет строки программы сверху вниз, а комментарии пропускает. Ты
умеешь отличать имя аргумента в описании команды от значения в её вызове.
Теперь твоя программа показывает два разных поля, находит клетку по координатам
`(x, y)` и показывает корабль или промах.

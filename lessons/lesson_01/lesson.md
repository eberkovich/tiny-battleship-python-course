# Первое знакомство

В этом курсе ты полностью создашь игру «Морской бой» с однопалубными
кораблями. Каждый такой корабль занимает одну клетку.

Проходя уроки, ты сам напишешь всю логику игры: расставишь корабли, научишь
программу проверять попадания, добавишь ходы компьютера и определишь победителя.

Чтобы показывать поля, корабли и выстрелы, ты будешь использовать
вспомогательные команды. С ними мы познакомимся в следующих разделах.

<!-- section: support -->
# Вспомогательные команды

Чтобы твоя программа узнала о вспомогательных командах, в начале каждой
программы уже есть строка:

```python
from battleship_ui import *
```

Она подключает вспомогательные команды к твоей программе. Эту строку изменять
не нужно.

<!-- section: api -->
# Как устроена команда

Вспомогательные команды, которыми ты будешь пользоваться, — это функции Python.
Функция обозначает действие понятным именем, чтобы программа могла выполнить
его в нужный момент.

Чтобы выполнить функцию, в программе пишут её имя и круглые скобки. Такая
запись называется вызовом функции. Некоторым функциям нужна дополнительная
информация внутри скобок. Её называют аргументом.

Первая вспомогательная команда — `show_board`. Она показывает игровое поле.
В описании команды её записывают так:

```python
show_board(board)
```

Это ещё не готовый вызов, а подсказка о его устройстве. `show_board` — имя
функции, а `board` — имя аргумента. Оно означает «игровое поле» и показывает,
какое значение нужно поставить на это место. Само слово `board` не выбирает
конкретное поле.

Для аргумента с именем `board` подходят два значения:

- `PLAYER` — твоё поле;
- `ENEMY` — поле противника.

> [!EXAMPLE]
> **Пример:** передадим в аргумент с именем `board` значение `ENEMY`.
>
> ```python
> show_board(ENEMY)
> ```
>
> В этом вызове `show_board` — имя функции, а `ENEMY` — значение аргумента.
> Python передаст значение `ENEMY` на место с именем `board`, и функция поймёт,
> что нужно показать поле противника. После запуска появится пустое поле
> размером 10 на 10 клеток.

---

Теперь сравним описание команды и готовый вызов. У аргумента есть две разные
части, которые важно не путать:

- **имя аргумента** встречается в описании команды и объясняет, какая
  информация нужна;
- **значение аргумента** записывается в вызове и сообщает, что именно нужно
  использовать сейчас.

В описании `show_board(board)` слово `board` — имя аргумента. В готовом вызове
`show_board(ENEMY)` на его месте стоит выбранное значение `ENEMY`. Имя
аргумента в описании остаётся тем же, а значение ты выбираешь для конкретного
действия.

Имя функции, круглые скобки и значение внутри образуют вызов функции. Правила
такой записи называются синтаксисом вызова. Функции встречаются в самых разных
программах: они позволяют повторять нужное действие, обращаясь к нему по имени.

<!-- section: execution -->
# Строка за строкой

Программа состоит из строк. В программах этого урока Python начинает с верхней
строки, выполняет её и переходит к следующей. Так он движется сверху вниз,
обрабатывая строки по одной.

> [!EXAMPLE]
> **Пример:** проследим, что Python сделает с двумя строками программы.
>
> ```python
> from battleship_ui import *
> show_board(ENEMY)
> ```
>
> Сначала первая строка подключит вспомогательные команды. Затем вторая строка
> покажет поле противника.

Порядок строк важен. Сначала программа должна подключить вспомогательные
команды, и только после этого их можно вызывать.

<!-- section: comments -->
# Комментарии в коде

Иногда рядом с кодом нужна подсказка для человека, но Python не должен её
выполнять. Такая строка называется комментарием и начинается со знака `#`.

> [!EXAMPLE]
> **Пример:** комментарий объясняет действие следующей строки.
>
> ```python
> # Показываем поле противника.
> show_board(ENEMY)
> ```
>
> Python пропустит первую строку, потому что она начинается с `#`, а затем
> выполнит вызов `show_board(ENEMY)`.

Python не выполняет комментарии, а сразу переходит к следующей строке. Пустые
строки тоже не выполняют действий: они только помогают разделять код на понятные части.

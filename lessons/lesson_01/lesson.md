# Команды игрового поля

В начале файла уже есть строка:

```python
from battleship_ui import *
```

Она добавляет команды для работы с «Морским боем».

---

Команда `show_board` показывает игровое поле:

```python
show_board(board)
```

Аргумент:

- `board` — игровое поле. Возможные значения:
  - `PLAYER` — твоё поле;
  - `ENEMY` — поле противника.

Пример — показать поле противника:

```python
show_board(ENEMY)
```

После запуска появится пустое поле размером 10 на 10 клеток.

---

Команда `draw_deck` рисует одну палубу корабля:

```python
draw_deck(board, x, y, state)
```

Аргументы:

- `board` — игровое поле. Возможные значения:
  - `PLAYER` — твоё поле;
  - `ENEMY` — поле противника;
- `x` — номер столбца;
- `y` — номер строки;
- `state` — состояние палубы. Возможные значения:
  - `DECK_IDLE` — палуба не повреждена.

```python
draw_deck(PLAYER, 5, 7, DECK_IDLE)
```

После запуска на поле игрока появится палуба в клетке `(5, 7)`.

---

Команда `show_miss` показывает промах:

```python
show_miss(board, x, y)
```

Аргументы:

- `board` — игровое поле. Возможные значения:
  - `PLAYER` — твоё поле;
  - `ENEMY` — поле противника;
- `x` — номер столбца;
- `y` — номер строки.

```python
show_miss(ENEMY, 8, 6)
```

После запуска на поле противника появится промах в клетке `(8, 6)`.

# Координаты клетки

Каждая клетка имеет адрес `(x, y)`.

- `x` — номер столбца слева направо;
- `y` — номер строки сверху вниз;
- на поле 10 столбцов и 10 строк, поэтому `x` и `y` имеют значения от 1 до 10.

Первая координата всегда означает `x`, а вторая — `y`:

```python
draw_deck(PLAYER, 6, 3, DECK_IDLE)
```

Клетка `(6, 3)` находится в шестом столбце и третьей строке.

# Один адрес — два числа

Координаты `x` и `y` всегда описывают одну клетку. Их можно сохранить вместе
как один адрес:

```python
cell = (6, 4)
```

Круглые скобки объединяют значения, а запятая разделяет их. Теперь переменная
`cell` хранит весь адрес. Строку можно прочитать так: «сохрани адрес 6, 4 под
именем cell». Python создаёт одно значение из двух чисел и сохраняет его.
Команда `print(cell)` покажет `(6, 4)`.

Порядок важен: первое число остаётся координатой `x`, второе — координатой `y`.

# Достаём координаты

Чтобы снова получить отдельные координаты, поставь два имени слева от `=`:

```python
cell = (6, 4)
x, y = cell
```

Python возьмёт первое число адреса и сохранит его в `x`, а второе — в `y`.
Это называется распаковкой адреса. После неё знакомую команду можно вызвать так:

```python
draw_deck(PLAYER, x, y, DECK_IDLE)
```

На своём поле появится корабль в клетке `(6, 4)`.

Слева должно быть столько имён, сколько значений находится в адресе. Если
случайно написать `y, x = cell`, координаты поменяются местами.

<!-- section: recap -->
# Итоги урока

Один адрес клетки хранит сразу две связанные координаты. Ты умеешь сохранить
адрес, распаковать его в `x` и `y` и использовать для корабля.

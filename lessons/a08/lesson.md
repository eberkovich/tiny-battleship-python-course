# Программа задаёт вопросы

<!-- section: why_input -->
## Зачем программе твои ответы

До сих пор все числа и слова были записаны прямо в коде. Чтобы программа работала с другими данными, приходилось менять файл. Но пользователю удобнее **сообщить данные уже запущенной программе**.

В калькуляторе ты вводишь числа и выбираешь действие. В YouTube пишешь, какое видео ищешь. В приложении погоды указываешь город. В Minecraft нажимаешь клавиши и щёлкаешь мышью, чтобы двигаться и строить. Всё это — **ввод пользователя**: данные или действия, которые получает программа.

В этом уроке наши программы будут задавать вопросы и получать ответы, набранные на клавиатуре. Один и тот же код сможет работать с разными ответами.

<!-- section: receive_answer -->
## Как получить и сохранить ответ

Функция **input()** ждёт, пока человек введёт текст и нажмёт **Enter**. Полученный ответ можно сохранить в переменной.

> [!EXAMPLE]
> **Пример:** программа спрашивает любимый цвет. Пользователь отвечает «синий».
>
> ```python
> print("Какой цвет тебе нравится?")
> color = input()
> print(color)
> ```
>
> ```input
> синий
> ```
>
> ```output
> Какой цвет тебе нравится?
> синий
> ```
>
> Первый print показывает вопрос. На строке с input() программа ждёт ответ. После Enter ответ сохраняется в color («цвет»), и последний print показывает его. Блок «Ввод пользователя» — то, что человек набрал; блок «Вывод программы» — то, что показали вызовы print.

Здесь у input нет аргументов, поэтому между скобками ничего нет. Скобки всё равно нужны: они обозначают вызов функции. Вопрос мы показали отдельным print перед этим вызовом.

В color = input() Python сначала получает ответ справа от =, затем сохраняет его под именем color. До нажатия Enter он не перейдёт к последнему print.

Если запустить тот же файл ещё раз и ввести «зелёный», последний print покажет «зелёный». Менять код для этого не нужно. input получает **текст**, даже если человек набрал цифры. Работать с такими ответами как с числами научимся в следующем уроке.

Когда нажмёшь «Запустить» в учебнике, появится окно для ответа. Введи текст и нажми Enter. Кнопка «Остановить» позволяет прервать запуск.

## Как тебя представить?

Напиши программу для представления участника игры. Сначала спроси **«Как тебя представить?»**, затем получи ответ с помощью input и сохрани его в переменной nickname («ник»).

После ответа выведи на отдельной строке **«Наш участник:»**, а на следующей — введённый ник. Программа должна использовать ответ человека, а не заранее записанное имя. При новом запуске попробуй другой ник.

<!-- section: q_wait -->
## Когда появится сообщение?

Прочитай программу. Человек собирается ввести «Луна», но **ещё не нажал Enter**.

```python
print("Как зовут героя?")
hero = input()
print("Ответ получен")
print(hero)
```

Что к этому моменту успела вывести программа? Выбери ответ, не запуская код.

<!-- section: several_answers -->
## Несколько ответов

Если нужны два разных ответа, сохрани их под разными именами. Тогда второй ответ не заменит первый.

> [!EXAMPLE]
> **Пример:** программа запоминает имя питомца и его любимую игрушку.
>
> ```python
> print("Как зовут питомца?")
> pet = input()
> print("Какая у него любимая игрушка?")
> toy = input()
> print(pet)
> print(toy)
> ```
>
> ```input
> Барсик
> мяч
> ```
>
> ```output
> Как зовут питомца?
> Какая у него любимая игрушка?
> Барсик
> мяч
> ```
>
> После первого ответа pet («питомец») хранит «Барсик». После второго toy («игрушка») хранит «мяч». Программа получает ответы по очереди и только потом выводит оба. Вторая переменная не меняет первую.

Если бы во второй строке с input снова стояло pet = input(), прежнее значение pet заменилось бы новым. Разные имена нужны не ради количества переменных: они позволяют сохранить разные данные, которые ещё понадобятся.

<!-- section: lost_answer -->
## Куда пропал первый ответ?

Программа спрашивает название команды и её девиз. Она должна сохранить оба ответа и вывести сначала название, затем девиз, каждое на своей строке.

```python
print("Как называется команда?")
answer = input()
print("Какой у команды девиз?")
answer = input()
print(answer)
print(answer)
```

Сейчас вместо названия она повторяет девиз. Исправь программу. Вопросы и их порядок оставь прежними. Не подставляй готовые ответы: название и девиз вводит человек.

> Открой редактор → выполни задание → сохрани изменения → нажми **«Запустить»**.

<!-- section: one_line -->
## Текст и значение в одной строке

До сих пор каждый print получал один аргумент. Но ему можно передать несколько: **раздели их запятыми внутри скобок**. print покажет значения в одной строке и сам поставит между ними пробелы.

> [!EXAMPLE]
> **Пример:** подписываем очки игрока, а затем начинаем новую строку.
>
> ```python
> points = 24
> print("Очки:", points)
> print("Раунд окончен")
> ```
>
> ```output
> Очки: 24
> Раунд окончен
> ```
>
> В первом вызове два аргумента: текст «Очки:» и значение points. Запятая разделяет аргументы в коде, но в выводе вместо неё появляется пробел. Следующий вызов print начинает новую строку.

Аргументы выводятся в том порядке, в котором ты их записал. Текст в кавычках остаётся текстом, а имя без кавычек означает значение переменной. Так можно объединить пояснение и полученный ответ.

<!-- section: announcement -->
## Собери объявление

В бюро находок нужно объявить, какой предмет нашли и где. Спроси **сначала предмет, затем место**, получи оба ответа с помощью input и сохрани их под разными именами.

После обоих ответов выведи **одну строку** такого вида: **«Найден предмет: <предмет> Место: <место>»**. Вместо <предмет> и <место> должны появиться введённые ответы, без угловых скобок. Между словами и ответами — по одному пробелу.

Используй один print с несколькими аргументами. Не записывай ответы заранее в коде.

<!-- section: story -->
## Смешная история

Сделай программу, которая собирает короткую историю из ответов человека. Получи **три ответа в таком порядке**:

- кто герой истории — имя или название, например «робот»;
- как называется место действия — например «Лунная база»;
- что герой умеет делать — действие, например «есть печенье».

Сначала получи и сохрани все ответы. Потом выведи историю из трёх строк по этому шаблону:

- **В месте под названием <место> появился герой: <герой>**
- **<герой> объявляет: моя суперсила — <действие>**
- **Теперь <место> ждёт новых приключений!**

Угловые скобки не выводи: на их месте должны быть ответы человека. Между частями каждой строки оставляй один пробел. Заметь: герой и место нужны в истории больше одного раза, но спрашивать их повторно не надо.

Сам выбери имена переменных и составь программу. Не меняй файл между вопросами. После первого запуска попроси кого-нибудь придумать другие ответы и прочитай новую историю.

> Открой редактор → выполни задание → сохрани изменения → нажми **«Запустить»**.

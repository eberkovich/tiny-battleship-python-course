# Группируем вычисления

<!-- section: grouping -->
## Сначала то, что в скобках

Иногда сложение нужно выполнить раньше умножения. Для этого часть выражения заключают в **круглые скобки**. Python сначала вычисляет выражение внутри них.

> [!EXAMPLE]
> **Пример:** одни и те же числа и действия дают разные результаты из-за скобок.
>
> ```python
> print(4 + 3 * 2)
> print((4 + 3) * 2)
> ```
>
> ```output
> 10
> 14
> ```
>
> В первой строке Python сначала умножает 3 на 2, затем прибавляет 4. Во второй сначала складывает 4 и 3 внутри скобок, получает 7, затем умножает 7 на 2.

В вызове print((4 + 3) * 2) **внутренние скобки** окружают 4 + 3 и задают порядок вычислений. **Внешние скобки** стоят после имени print и вокруг всего его аргумента — как в знакомом вызове print(14).

Внешние скобки нужны для вызова функции. Они не заставляют выполнять сложение перед умножением: для этого здесь нужна ещё одна пара, вокруг 4 + 3.

Прочитай программу, пока не запускаешь её:

Какое число она выведет? Учти, какую часть выражения нужно вычислить первой.

## Получи нужное число

В файле записано вычисление:

```python
print(11 + 7 * 3)
```

Добавь **одну пару скобок внутри вызова print**, чтобы результатом стало число 54. Числа, знаки действий и их порядок не меняй. Программа должна вывести только это число.

<!-- section: pairs -->
## Каждой скобке нужна пара

Для каждой открывающей скобки должна быть закрывающая. Когда внутри вызова есть скобки для вычисления, нужно закрыть и их, и сам вызов print.

> [!EXAMPLE]
> **Пример:** две открывающие скобки и две закрывающие.
>
> ```python
> print(12 * (5 + 2))
> ```
>
> ```output
> 84
> ```
>
> Скобка после числа 2 закрывает выражение 5 + 2. Следующая закрывает вызов print. Сначала Python складывает 5 и 2, затем умножает результат на 12 и выводит его.

Обе закрывающие скобки здесь стоят рядом. Это не ошибка и не повтор: каждая закрывает свою открывающую скобку. Если пропустить одну, Python не сможет выполнить строку.

## Почини скобки

Программа должна сложить 13 и 2, умножить результат на 9 и вывести полученное число. В записи не хватает скобки:

```python
print(9 * (13 + 2)
```

Добавь недостающую скобку. Не меняй числа, знаки действий и имеющиеся скобки. После исправления программа должна вывести одно число без слов.

> [!NOTE]
> Открой редактор → выполни задание → сохрани изменения → нажми **«Запустить»**.

Запиши выбранное вычисление в одном вызове print. Программа должна вычислить и вывести только длину более длинной верёвки в сантиметрах, без слов. Готовый ответ вместо вычислений не записывай.

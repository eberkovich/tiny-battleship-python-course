# Добавляем в список

Сейчас адреса флота известны заранее. Позже игрок будет выбирать клетки по
одной, поэтому программа не сможет сразу записать готовый список кораблей. Она
начнёт с пустого списка и будет добавлять каждый новый адрес.

Так работают многие программы: они постепенно собирают результаты, ответы или
сделанные ходы. Пустой список выглядит так:

```python
values = []
```

Команда `append` добавляет одно значение в конец списка:

```python
values.append(value)
```

Перед точкой стоит имя списка. После точки — команда для этого списка.
Строку `values.append(6)` можно прочитать так: «в список values добавь число
6». Python находит существующий список и изменяет его: новое значение
становится последним.

Аргумент:

- `value` — значение, которое нужно добавить.

Пример:

```python
values = []
values.append(6)
values.append(9)
print(values)
```

После запуска появится `[6, 9]`. `len(values)` теперь вернёт `2`.
Если поменять две команды `append` местами, поменяется и порядок значений в
списке.

## Упражнение 1. Добавь число

Добавь число `5` в готовый список. Выведи сначала весь список, затем его длину.
В результате должны появиться `[2, 5]` и `2`.

Добавь адрес `(7, 4)` в готовый список `ships`. Затем возьми добавленный адрес
из списка по его индексу, сохрани его координаты в `x` и `y` и нарисуй

# Итоги урока

Пустой список можно заполнять постепенно. `append` добавляет новое значение в
конец, а `len` показывает, сколько значений уже собрано.

# Начинаем с пустого списка

Сейчас адреса флота известны заранее. Позже игрок будет выбирать клетки по
одной, поэтому программа не сможет сразу записать готовый список кораблей. Она
начнёт с пустого списка и будет добавлять каждый новый адрес.

Так работают многие программы: они постепенно собирают результаты, ответы или
сделанные ходы. Пустой список выглядит так:

```python
values = []
```

> [!EXAMPLE]
> **Пример:** создадим пустой список и покажем его.
>
> ```python
> values = []
> print(values)
> ```
>
> После запуска появится `[]`: квадратные скобки есть, но значений между ними
> пока нет.

# Добавляем значение в список

Пустой список уже умеет хранить будущие значения. Теперь программе нужен
способ добавлять их по одному.

Команда `append` добавляет одно значение в конец списка:

```python
values.append(value)
```

Перед точкой стоит имя списка, а после точки — команда для этого списка. Такая
запись просит существующий список выполнить действие со своими значениями.

Аргумент:

- `value` — значение, которое нужно добавить.

> [!EXAMPLE]
> **Пример:** добавим в пустой список сначала `6`, затем `9`.
>
> ```python
> values = []
> values.append(6)
> values.append(9)
> print(values)
> ```
>
> Строку `values.append(6)` можно прочитать так: «в список values добавь число
> 6». После запуска появится `[6, 9]`. `len(values)` теперь вернёт `2`.

Python находит существующий список и изменяет его: новое значение становится
последним.

Если поменять две команды `append` местами, поменяется и порядок значений в
списке.

> [!EXAMPLE]
> **Пример:** порядок команд определяет порядок значений в списке.
>
> ```python
> values = []
> values.append(8)
> values.append(3)
> print(values)
> ```
>
> Сначала добавляется `8`, затем `3`, поэтому программа покажет `[8, 3]`.

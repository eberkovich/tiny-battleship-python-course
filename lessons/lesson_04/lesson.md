# Несколько значений вместе

У каждого корабля есть адрес. Если хранить их только в отдельных переменных
`ship_1`, `ship_2`, `ship_3`, работать с целым флотом будет неудобно. Программе
нужно одно значение, которое объединит все адреса.

Для этого в Python есть список. Список хранит несколько значений по порядку.

> [!EXAMPLE]
> **Пример:** сохраним в одном списке три числа.
>
> ```python
> numbers = [2, 5, 8]
> print(numbers)
> ```
>
> Квадратные скобки обозначают список, а запятые разделяют его значения.
> Порядок сохраняется: сначала `2`, затем `5`, затем `8`. После запуска
> появится `[2, 5, 8]`.

Списки нужны не только для кораблей. В них можно собрать результаты попыток,
сообщения или любые другие значения, с которыми программа будет работать как
с одной группой.

> [!EXAMPLE]
> **Пример:** вместо чисел список может хранить адреса двух клеток.
>
> ```python
> cells = [(1, 2), (4, 6)]
> ```

Не путай круглые и квадратные скобки: круглые объединяют координаты одного
адреса, а квадратные собирают несколько адресов в список.

# Сколько значений в списке

Когда список становится длинным, программе нужен способ самой посчитать его
значения. Функция `len` возвращает количество значений в списке.

```python
len(value)
```

Аргумент:

- `value` — список, значения которого нужно посчитать.

> [!EXAMPLE]
> **Пример:** посчитаем значения в списке `numbers`.
>
> ```python
> numbers = [2, 5, 8]
> print(len(numbers))
> ```
>
> В результате появится `3`. `len` не меняет список, а только сообщает, сколько
> в нём значений.

# Как взять значение из списка

Собрать флот недостаточно: программе понадобится брать из него адреса
кораблей. У каждого значения в списке есть номер — индекс. Индексы начинаются
с нуля.

> [!EXAMPLE]
> **Пример:** возьмём из списка первое и третье числа.
>
> ```python
> numbers = [10, 20, 30]
> print(numbers[0])
> print(numbers[2])
> ```
>
> Квадратные скобки после имени списка выбирают одно значение. `numbers[0]`
> означает первое значение списка, а `numbers[2]` — третье. Поэтому программа
> покажет `10`, затем `30`.

Эту запись можно прочитать так: «возьми из numbers значение с индексом 2».
Python сначала находит список `numbers`, затем отсчитывает в нём значение с
нуля и возвращает выбранное значение. Сам список при этом не меняется.

> [!EXAMPLE]
> **Пример:** то же действие подходит для списка адресов. Возьмём второй адрес
> и распакуем его.
>
> ```python
> cells = [(2, 6), (7, 3)]
> cell = cells[1]
> x, y = cell
> ```
>
> В `cell` попадёт второй адрес `(7, 3)`, затем он распакуется в `x` и `y`.
В списке из трёх значений есть индексы `0`, `1` и `2`. Индекса `3` в нём нет:
попытка взять такое значение остановит программу с ошибкой.

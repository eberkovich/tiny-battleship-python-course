# Несколько значений вместе

Для целого флота понадобится много адресов. Список хранит несколько значений в
одном месте:

```python
numbers = [2, 5, 8]
```

Квадратные скобки обозначают список, а запятые разделяют его значения. Порядок
сохраняется: сначала `2`, затем `5`, затем `8`. Строку можно прочитать так:
«сохрани список из трёх чисел под именем numbers». Python создаёт одно значение
— список — и сохраняет в нём остальные значения по порядку.

Функция `len` считает значения в списке:

```python
len(value)
```

Аргумент:

- `value` — список, значения которого нужно посчитать.

Пример:

```python
numbers = [2, 5, 8]
print(len(numbers))
```

В результате появится `3`. Список может хранить и знакомые адреса клеток:

```python
cells = [(1, 2), (4, 6)]
```

Не путай круглые и квадратные скобки: круглые объединяют координаты одного
адреса, а квадратные собирают несколько адресов в список.

# Итоги урока

Список хранит несколько значений в одном порядке, а `len` считает их. Теперь
адреса трёх кораблей собраны вместе, и счётчик вычисляется по списку.

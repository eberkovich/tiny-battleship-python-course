## Программа и комментарии

Программа — это инструкции для компьютера. Их записывают на языке программирования. В этом курсе мы будем использовать язык **Python**. Текст программы часто называют **кодом**.

Сначала мы научимся читать и писать маленькие программы. Потом используем знакомые приёмы, чтобы сделать «Морской бой». В этом уроке пока не нужно писать код.

В программе можно оставить пояснение для человека. Его называют **комментарием**. Если строка начинается со знака #, Python не выполняет написанное в ней.

> [!EXAMPLE]
> **Пример:** в файле записана только эта строка:
>
> ```python
> # Нарисуй солнце
> ```
>
> Просьба нарисовать солнце написана после #. Она обращена к читателю. Python пропустит эту строку: при запуске ничего не появится.

Знак # отмечает начало комментария. В заданиях мы будем писать после него, что тебе нужно сделать.

## Кому адресована подсказка

Комментарий может содержать задание. Выполнять его будет человек, а не Python.

> [!EXAMPLE]
> **Пример:** в файле есть подсказка:
>
> ```python
> # Выбери название для робота
> ```
>
> Тебе предлагают выбрать название. Python пропускает строку с #: он не выбирает название и не выводит комментарий на экран.

В следующем уроке ты будешь писать инструкции под такими комментариями. Эти инструкции Python уже сможет выполнить.

## Программа и комментарии

Когда ты пишешь программу, ты даёшь компьютеру инструкции. Python — язык, на котором можно записать эти инструкции.

Сначала мы научимся читать и писать маленькие программы. Потом используем знакомые приёмы, чтобы сделать «Морской бой». В этом уроке пока не нужно писать код.

В файле с программой бывает и текст для человека. Его называют **комментарием**. Строка, которая начинается со знака #, — комментарий. Python не выполняет написанное в ней.

> [!EXAMPLE]
> **Пример:** в файле записана только эта строка:
>
> ```python
> # Нарисуй солнце
> ```
>
> Это подсказка читателю, а не инструкция для Python. При запуске такой файл не нарисует солнце и ничего не покажет.

Знак # можно прочитать как «дальше написан комментарий». В этом курсе комментарии в заданиях будут подсказывать тебе, что нужно сделать.

<!-- section: directions -->
## Кому адресована подсказка

Комментарий может описывать задание, но он не выполняет его за тебя. Если в комментарии просят придумать что-нибудь, это просьба к человеку, который читает файл.

> [!EXAMPLE]
> **Пример:** в файле есть подсказка:
>
> ```python
> # Выбери название для робота
> ```
>
> Название выбирает человек. Python не выбирает его и не показывает этот текст при запуске.

Позже под такими подсказками ты будешь писать настоящие инструкции для Python. Как их записывать, узнаешь в следующем уроке.

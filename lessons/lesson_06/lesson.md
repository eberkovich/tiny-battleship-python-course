# Команды по кругу

Во флоте уже несколько кораблей. Если для каждого адреса писать отдельный
`draw_deck`, программа станет длинной, хотя действие всё время одинаковое.
Нужен способ сказать: «выполни этот шаг для каждого значения списка».

Для такого повторения в Python есть цикл `for`:

```python
numbers = [3, 6, 9]

for number in numbers:
    print(number)
```

После `for` стоит переменная `number`. На каждом повторе в неё попадает
следующее значение списка. Слово `in` можно прочитать как «из», а двоеточие
`:` открывает повторяемый блок.

Команда внутри блока сдвинута вправо четырьмя пробелами. Такой сдвиг называется
отступом. Python повторит только команды с этим отступом. В результате появятся
три строки: `3`, `6`, `9`.

Всю конструкцию можно прочитать так: «для каждого числа из numbers покажи это
число». Python берёт значения по одному, каждый раз сохраняет очередное в
`number` и выполняет блок с отступом. Частые ошибки — забытое двоеточие после
списка или отсутствующий отступ перед командой блока.

Цикл описывает общий способ работы со всей группой, а не отдельную команду для
каждого значения. Такой шаг алгоритма пригодится не только для кораблей: циклом
можно проверять ответы, показывать сообщения или обрабатывать результаты.

# Цикл по адресам

Если список хранит адреса, цикл может сразу разделять каждый адрес на `x` и
`y` — распаковывать его:

```python
cells = [(3, 6), (7, 2)]

for x, y in cells:
    draw_deck(PLAYER, x, y, DECK_IDLE)
```

На первом повторе `x` и `y` получат координаты `(3, 6)`, на втором — `(7, 2)`.
На своём поле появятся два корабля.

# Итоги урока

Цикл `for` повторяет блок команд для каждого значения списка. Благодаря циклу
десять кораблей рисуются одной короткой частью программы.

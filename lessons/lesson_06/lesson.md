# Одно действие много раз

Во флоте уже несколько кораблей. Если для каждого адреса писать отдельный
`draw_deck`, программа станет длинной, хотя действие всё время одинаковое.
Нужен способ сказать: «выполни этот шаг для каждого значения списка».

Для такого повторения в Python есть цикл `for`.

> [!EXAMPLE]
> **Пример:** цикл по очереди выведет три числа из списка.
>
> ```python
> numbers = [3, 6, 9]
> for number in numbers:
>     print(number)
> ```
>
> После `for` стоит переменная `number`. На каждом повторе в неё попадает
> следующее значение списка. Слово `in` можно прочитать как «из», а двоеточие
> в конце первой строки открывает повторяемый блок.
>
> Команда, которую нужно повторять, сдвинута вправо четырьмя пробелами. Python
> повторит её для каждого числа. В результате появятся три строки: `3`, `6`,
> `9`.

Всю конструкцию можно прочитать так: «для каждого числа из numbers покажи это
число». Python берёт значения по одному, каждый раз сохраняет очередное в
`number` и выполняет сдвинутую вправо команду. Частая ошибка — забытое
двоеточие после списка.

Цикл описывает общий способ работы со всей группой, а не отдельную команду для
каждого значения. Такой шаг алгоритма пригодится не только для кораблей: циклом
можно проверять ответы, показывать сообщения или обрабатывать результаты.

# Какие команды повторяет цикл

Циклу нужно отличать повторяемые команды от тех, которые идут после него.
Сдвиг строки вправо четырьмя пробелами называется отступом. Все команды с
таким отступом образуют блок цикла и выполняются на каждом повторе.

> [!EXAMPLE]
> **Пример:** проследим два повторения короткого цикла.
>
> ```python
> values = [4, 7]
> for value in values:
>     print(value)
> ```
>
> На первом повторе в `value` попадёт `4`, и программа покажет `4`. На втором
> повторе в `value` попадёт `7`, и программа покажет `7`. После этого значения
> в списке закончатся, и цикл завершится.

Если убрать отступ перед `print(value)`, команда перестанет относиться к циклу.
Python либо сообщит об ошибке, либо выполнит строку уже после цикла — это
зависит от оставшегося кода.

# Цикл по адресам

Цикл уже умеет брать из списка числа по одному. Для флота нужно повторить то же
действие с адресами: взять очередной адрес, получить `x` и `y`, затем нарисовать
корабль. Цикл может сразу распаковывать каждый адрес.

> [!EXAMPLE]
> **Пример:** цикл распакует каждый адрес и нарисует два корабля.
>
> ```python
> cells = [(3, 6), (7, 2)]
> for x, y in cells:
>     draw_deck(PLAYER, x, y, DECK_IDLE)
> ```
>
> На первом повторе `x` и `y` получат координаты `(3, 6)`, на втором —
> `(7, 2)`. На своём поле появятся два корабля.
